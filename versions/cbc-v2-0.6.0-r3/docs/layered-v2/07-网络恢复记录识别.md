## 修复边界

不根据文本单独排除消息，不泛化排除isMeta、system-reminder或skipRun。429、配额、其他未知恢复格式不在本次自动豁免范围。后续独立真实输入仍保留。Hook新输入边界不因这项原生分类被忽略。
