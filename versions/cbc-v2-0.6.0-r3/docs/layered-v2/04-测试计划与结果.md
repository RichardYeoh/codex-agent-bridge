# 测试计划与结果

## 覆盖矩阵

| 组 | 场景 | 必须成立 |
|---|---|---|
| 正常 | 首次派工、同会话返工、冷恢复、快任务 | 精确请求关联；验收仅主控 |
| 消息 | 重复、乱序、丢ACK、写入前后崩溃、相同ID异内容 | 幂等；未知不重发；冲突显式 |
| 外部输入 | 其他会话、管理命令、交付后聊天、运行中插入 | 无关不归属；历史不回退；冲突不冒领 |
| 资源 | 断网、429、配额、IPC拒绝、PID/terminal复用 | 观察与执行分开；不绕审批 |
| 存储 | 坏事件、截断、路径别名、并发、超限、快照篡改 | 限定故障范围；拒绝不伪成功 |
| 交付 | 无报告、错误请求、错轮、晚到、产物变更 | 不靠idle/文件存在完成；冻结版本可审 |
| 通知 | 重投、丢ACK、离线、预算耗尽 | 不重复执行；不把queued称consumed |
| 发布 | 旧协议继续、运行中不热切、基线变化、回滚 | 不覆盖增量；不操作业务任务 |

## 证据等级

纯内核测试、CLI隔离模拟、真实本地CBC、真实业务迁移分别记录。429/配额/断网使用故障注入，不故意消耗真实配额；真实用户审批不制造危险动作。每次执行记录命令、源码摘要、数量、失败及跳过原因。

## 已执行结果

最终合并执行`node --test --test-concurrency=4 agent-bridge/test/*.test.js tools/prepare-layered-release.test.cjs tools/layered-entry-router.test.cjs`：620项，617通过、3跳过、0失败。离线`node tools/run-e2e.cjs`为8/8通过。跳过包含上游条件用例和Windows不允许文件symlink创建的子例；目录junction规范化已有成功用例。发布包实机检查单独写工程发布记录，不把上述模拟用例称作真实业务验证。

真实CBC独立工程测试：

| 场景 | 实际结果 |
|---|---|
| 第一轮故意错误函数 | 实际创建减法，主控独立发现；因Hook摘要适配缺陷，冻结命令拒绝，未误报成功 |
| 未确认输入恢复 | 精确原生文本加Hook对账，无重放，进入delivery_missing |
| 同会话返工 | 原ID修正加法，正负数验收通过；正确复述前轮记忆词；生成冻结交付 |
| 交付后普通聊天 | 实际得到独立回复；原派工events摘要与结果保持不变，accept成功 |
| 验收后新任务 | 原会话、原Pane复用；CLI退出0，观察器自动待审并退出 |
| 关闭Pane后冷恢复 | 新Pane沿登记的同一原生ID恢复；派工退出0，自动待审 |
| 自动通知 | 原线程队列取得queued回执，主控按key显式ack；不将queued声称已触发新模型回合 |
| 观察中断 | 人为设置180秒本地观察期限，超时未停止CBC；完成后正式recover恢复待审 |

试验仅用维护项目隔离状态。前置JSON规格类型错误和错误Workspace继承均在输入前失败并保留；前者未创建task，后者通过正式cancel收口后使用显式隔离Workspace。未对真实业务任务执行恢复、输入、取消或验收。

## 证据边界

审批、429、断网、通知失败、损坏文件、乱序及进程异常主要由隔离fixture注入验证，未故意消耗真实额度或制造危险审批。单机文件快照不是安全沙箱或跨设备事务；Herdr检查与TUI输入仍无原子CAS保证。不确定时保留未知和资源隔离，不能保证所有上游异常都能无人介入结束。
