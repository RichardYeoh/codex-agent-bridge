| 1 | `cd <dir> && node --test acceptance.test.js` | 退出码 0，全部 pass |

## 交付报告要求

写 Markdown 到协调器指定路径（`deliveries/round-NNN.md`），必须包含：

1. 完成内容（对应上面每一条要求）
2. 修改文件表：文件 / 新建或修改 / 说明
3. **实际执行的命令与真实输出**（原样粘贴，不得改写或省略失败信息）
4. 测试证据（通过数 / 失败数 / 退出码）
5. 未解决项（没有就写「无」）
6. 当前返工轮次

报告不得只声称完成；无法完成时明确写阻塞原因与已尝试的做法。

- [ ] 没有需要密钥/登录/付费/管理员权限的步骤
